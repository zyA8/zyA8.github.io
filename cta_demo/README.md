# A股 CTA 趋势跟踪 · 学习示例

一个**从零手写、开箱即用**的量化回测小系统，目标是让你看懂 CTA 策略是怎么跑起来的。

## 什么是 CTA

CTA 指"趋势跟踪"类策略。它**不预测涨跌**，而是"顺势而为"：

> 截断亏损，让利润奔跑（Cut losses short, let profits run）。

靠少数几波大趋势赚大钱，用止损把震荡市的小亏控制住。

## 目录结构

```
cta_demo/
├── main.py          # 入口：一条命令跑通全流程
├── config.py        # 所有可调参数集中在这里
├── data_loader.py   # 数据加载（默认合成行情，也可读本地 CSV）
├── indicators.py    # 技术指标（均线 / ATR / 唐奇安通道）
├── strategy.py      # CTA 策略（双均线 / 唐奇安 / 唐奇安+ATR止损）
├── backtest.py      # 回测引擎（下单 → 成交 → 持仓 → 平仓）
├── metrics.py       # 绩效指标（收益 / 回撤 / 夏普 / 胜率）
├── plot.py          # 可视化（价格+买卖点 / 资金曲线 / 回撤）
└── sweep.py         # 参数遍历（扫参数 + 热力图 + 识别过拟合）
```

数据流：`data_loader → strategy(生成信号) → backtest(撮合记账) → metrics + plot`

## 快速开始

```bash
# 1. 安装依赖（只需 numpy / pandas / matplotlib）
pip install numpy pandas matplotlib

# 2. 运行
python main.py
```

运行后会在当前目录生成 `result.png`，并在终端打印绩效指标和交易明细。

## 两个内置策略

| 策略 | 逻辑 | 适合 |
|------|------|------|
| 双均线 | 快线(5)上穿慢线(20)做多，下穿平仓 | 入门理解趋势 |
| 唐奇安突破 | 突破 20 日新高买入，跌破 10 日新低卖出 | 海龟交易法经典 |
| 唐奇安+ATR止损 | 突破 20 日新高买入，用"最高价-3×ATR"移动止损离场 | 理解自适应止损 |

在 `config.py` 里改 `STRATEGY` 即可切换，改 `FAST_MA` / `DONCHIAN_ENTRY` 等参数即可调参对比。

合成数据由 `SEED`（随机种子）控制：换一个数字就是换一种市场行情（有的单边上涨、有的震荡、有的下跌）。默认 `SEED=5` 是一段"上下震荡但方向不明"的行情——买入持有几乎不赚，却能看清趋势策略如何靠抓波段获利。

## 回测引擎的几个关键设计（重点理解）

1. **无前视偏差**：信号在 T 日收盘产生，T+1 日**开盘价**成交。
2. **真实成本**：买入收佣金，卖出收佣金 + 印花税（A股特有），双向都算滑点。
3. **整手交易**：A股一手 = 100 股，买入向下取整到整手。
4. **T+1 制度**：当天买入不能当天卖出（日线回测下影响很小）。

## 接入真实 A 股数据

用 [akshare](https://akshare.akfamily.xyz/) 免费拉数据（以沪深300指数为例）：

```python
import akshare as ak

df = ak.index_zh_a_hist(symbol="000300", period="daily",
                        start_date="20150101", end_date="20240101")
df = df.rename(columns={"日期": "date", "开盘": "open", "最高": "high",
                        "最低": "low", "收盘": "close"})
df = df.set_index("date")[["open", "high", "low", "close"]]
df.to_csv("data/000300.csv")
```

然后把 `config.py` 里改成：

```python
DATA_MODE = "csv"
CSV_PATH = "data/000300.csv"
```

## 参数遍历与过拟合

```bash
python sweep.py
```

会扫描"快线 × 慢线"的组合，打印按夏普排序的参数表，并生成 `sweep_heatmap.png` 热力图。

重点不是找到"最高分"的那组参数，而是看**最优参数周围是不是也普遍不错**——如果只有孤零零一个点特别好、周围全差，那多半是过拟合（碰运气），实盘往往失效。

## 进阶方向（课后练习）

- 加**仓位管理**：按风险（ATR）定仓位，而不是满仓（当前是满仓进出）
- **多品种/多周期**同时跑，组合分散
- 用股指期货实现**多空双向**（`LONG_ONLY = False`）
- 做**参数遍历**，看夏普/回撤随参数怎么变化（避免过拟合）

> 提醒：示例里的绩效只在合成数据上有意义，不要当成真实盈利预期。任何策略都要在真实数据 + 样本外 + 交易成本下验证。
